# Data safety form

Play Console → Policy and programs → App content → Data safety. These answers match what the app does today and what `padelrival.co.uk/privacy` says. If you add push notifications, payments, analytics or ads later, update this form at the same time.

## Overview questions

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | Yes |
| Is all of the user data collected by your app encrypted in transit? | Yes (everything goes over HTTPS) |
| Do you provide a way for users to request that their data is deleted? | Yes (in the app, and at https://padelrival.co.uk/delete-account) |

## Data types collected

For every type below, answer **"Collected: Yes, Shared: No"**. Google doesn't count the companies that run the service for you, such as hosting, database, email delivery and the AI coach providers, as "sharing". Google sign-in only happens when the player chooses it.

For each type, set processing to **"Not processed ephemerally"** unless the table says otherwise.

| Category → data type | Required or optional | Purposes to tick |
|---|---|---|
| Personal info → **Name** | Required (display name) | App functionality, Account management |
| Personal info → **Email address** | Optional (accounts can use a username only) | Account management, App functionality |
| Personal info → **User IDs** | Required (account ID and @username) | App functionality, Account management |
| Personal info → **Other info** | Optional (avatar and preferred court side) | App functionality |
| App activity → **App interactions** | Required | App functionality, Analytics |
| App activity → **Other user-generated content** | Required (match results, venue names, open-match notes, guest names) | App functionality |
| App info and performance → **Crash logs** | Required | App functionality, Analytics |
| App info and performance → **Diagnostics** | Required | App functionality, Analytics |

App interactions covers friends, reactions, club check-ins, joining open matches and notifications.

## Data types NOT collected (leave unticked)

- **Location** (precise and approximate). "I'm playing today" stores a club the player picks, not the device location.
- **Financial info.** There are no payments in the Android app.
- **Health and fitness.**
- **Messages, photos and videos, audio, files and docs, calendar, contacts.**
- **Web browsing history.**
- **Device or other IDs.** There's no advertising ID.
